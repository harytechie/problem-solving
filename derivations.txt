1. What is Model Comparison?

Model Comparison means comparing different machine learning models to find which model performs better for the same problem.

                        Student Data
                            ↓
                        [ KNN | Decision Tree | Random Forest ]
                            ↓
                        Compare Performance
                            ↓
                        Choose Model

2. Why do we compare models?
        Because every model will not perform equally well on every dataset.

Example:
                    ----------------------------
                    | Model         | Accuracy |
                    | ------------- | -------- |
                    | KNN           |      80% |
                    | Decision Tree |      88% |
                    | Random Forest |      94% |
                    ----------------------------
5. Give Test Data:

                Test Data
                ↓
                ───┬───────────────┬─────────────────┬───
                ↓               ↓                 ↓
                KNN        Decision Tree     Random Forest
                ↓               ↓                 ↓
                Prediction      Prediction       Prediction

6. Find Accuracy:How many predictions are correct?
                Actual:     Pass Pass Fail Pass
                Prediction: Pass Fail Fail Pass

Formula:

                Accuracy = Correct Predictions / Total Predictions × 100

                Therefore:

                Accuracy = 3 / 4 × 100 = 75%

                So KNN accuracy = 75%

7. Do the Same for Every Model:

                Decision Tree Accuracy:
                Actual:     Pass Pass Fail Pass
                Prediction: Pass Pass Pass Pass
                Accuracy = 3 / 4 × 100 = 75%

                Random Forest Accuracy:
                Actual:     Pass Pass Fail Pass
                Prediction: Pass Pass Fail Pass
                Accuracy = 4 / 4 × 100 = 100%
